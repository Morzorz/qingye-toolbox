# 轻页工具箱 1.1 — approved scope and AI extension

The user approved extending the existing Electron desktop application (Tauri migration cancelled) with Office-to-PDF, PDF utilities, image and audio/video conversion, and on-demand components. The user additionally requested AI invocation after installation. Default to standard local MCP plus CLI unless the user steers toward a particular client. Do not configure external AI accounts automatically.

## Components and interfaces

1. Shared operation engine: validated operation names and options, source files, destination directory, progress callback, AbortSignal. Supports pdf_compress, pdf_merge, pdf_split (page range extraction), pdf_to_images, images_to_pdf, image_convert (JPEG/PNG/WebP; quality/maximum dimension), office_to_pdf (doc/docx/xls/xlsx/ppt/pptx), audio_convert (mp3/wav/flac/m4a), video_convert (mp4 with quality and maximum height). Existing MuPDF compression is reused. PDF/image work runs in a worker; FFmpeg and LibreOffice run as subprocesses with shell disabled. All paths validated and originals preserved. No PDF-to-editable-Office promise.
2. Job service: serial execution, bounded history, start/status/cancel, per-file failure isolation, collision-free output commit, cleanup of partial temporary files, JSON results. PDF merge/images-to-PDF treat the ordered input list as one job. Large media streams through subprocess files instead of reading into memory. Cancellation terminates active subprocess/worker and stops the queue.
3. Components: discover existing FFmpeg/LibreOffice or download pinned packages with HTTPS/checksums, installation triggered explicitly from desktop settings only. Keep binaries outside app package. FFmpeg prebuilt binaries are from the build provider linked by the FFmpeg ecosystem, with source/license link and exact version. LibreOffice comes from the Document Foundation. Mac extracts app to user component storage; Windows downloads its official installer and launches the installer with user interaction. Status states distinguish downloaded/installer launched from verified ready; missing engine errors instruct user to finish installation or select executable. Automatic network install is never initiated by AI calls. Existing system installs/custom paths are supported. Failed downloads clean up and can be retried.
4. Desktop: preserve existing layout, navigation for PDF/Office/images/audio/video, operation and format controls, batch list and output directory. Component settings and AI connection page. AI page selects/removes allowed directories and generates MCP JSON/Codex TOML plus command path. No live ads until an ad source is specified.
5. Local AI: installed app --mcp runs stdio MCP without window; --cli accepts a JSON task. Shared core ensures same behavior as UI. MCP exposes capabilities, submit task, task status and cancellation. stdio uses the official SDK; stdout only contains protocol frames. Input/output paths are limited to explicitly configured allowed directories; canonical real paths reject symlink escapes. No remote port, arbitrary shell, file deletion or automatic client config writes. Settings are reread before each request so revocation takes effect. Jobs cancelled on client disconnect. Return output paths/sizes and errors, never document contents. Normal cloud ChatGPT is not assumed to discover a local app automatically.

## Constraints and testing

Built-in PDF/image input limit 500 MiB; audio/video allow larger inputs without buffering, maximum 20 GiB. All output filenames are generated, no arbitrary supplied output basename. Cap page rendering pixels and output count. Encrypted/signed PDFs rejected before rewrites. Font availability affects Office pagination, explicitly documented. Image animation is not supported silently: reject multi-frame images. Lowering resolution/quality can reduce fidelity; format conversion alone does not guarantee smaller files.

Tests: PDF/text/form regression; merge/split/render/images-to-PDF; image dimensions and output signatures; Office DOCX/XLSX/PPTX to PDF using available local runtime; actual short audio/video output and cancellation; root allowlist/symlink escape/missing permissions; official MCP client initialize/listTools/submit/poll/cancel; GUI operations and AI settings; packaged Mac app and installed-entrypoint MCP; Windows build inspection with honest runtime limits. No private user files in release/source artifacts.
