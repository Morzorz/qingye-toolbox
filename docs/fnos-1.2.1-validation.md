# 飞牛独立版 1.2.1 修复验证

日期：2026-10-14。

用户反馈：实际飞牛浏览器界面左侧菜单无法切换，处理方式下拉选项为空。尚未取得实际浏览器控制台日志，因此不能把实机根因确定为特定网关行为。

复现：在模拟飞牛登录网关中，把 `.mjs` 的响应类型改为 `application/octet-stream`，旧版模块脚本被浏览器拒绝，初始下拉选项为空。浏览器回归测试在等待选项初始化时失败。

修复：将 NAS 桥接代码、操作目录和界面代码编译为一个普通脚本，直接随 HTML 交付。浏览器不再请求外部模块或依赖相对脚本地址。CSP 使用脚本内容的 SHA-256 授权，不开放 unsafe-inline。样式使用带版本号的绝对应用路径；HTML 禁止缓存。初始化失败时显示可反馈的错误信息。

已通过：

- 同样的模块 MIME 故障场景下，五类工具菜单全部可以切换，下拉选项正确；组件与目录页面正常。
- NAS 文件选择、PDF 转换、结果下载入口、电脑文件上传和转换。
- 浏览器没有页面异常，也没有外部脚本请求。
- 七项服务测试，包括精确 CSP 哈希、禁止 HTML 缓存、管理员鉴权、目录边界、上传任务归属与停止清理。

原生转换组件沿用 1.2.0 已验证的 Linux x86-64 运行环境。本次仍未连接用户的实际 NAS，需要安装 1.2.1 后确认实机表现；若仍异常，应结合页面提示与浏览器控制台继续定位。
