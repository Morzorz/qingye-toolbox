# 飞牛独立版 1.2.0 验证记录

验证日期：2026-10-14。目标设备：用户提供的 fnOS 1.2.0800 / Intel Core i5-6500（x86-64）。本次没有连接实际 NAS。

## 已通过

- 浏览器端：模拟飞牛登录网关，选择 NAS 文件、上传电脑文件、执行 PDF 转换、显示结果下载入口、查看授权目录；无页面脚本异常。
- 干净 Linux amd64 环境：禁用网络、以 UID/GID 1000 运行，只使用随包的 Node、FFmpeg、LibreOffice 与字体。容器没有预装 Office 或 FFmpeg。
- 实际转换：PDF 压缩、PDF 转图片、PNG 转 WebP、视频生成及转码、音轨转 MP3；对输出视频再次解码验证。
- 中文办公转换：DOCX、XLSX、PPTX 转 PDF；抽取中文文本并检查至少六个不同汉字字形；渲染截图目视检查没有方框、空白字或明显截断。
- 六项接口测试：残留上传清理、管理员鉴权及来源限制、目录边界及链接越界、上传重名处理及任务归属、上传目录链接攻击防护、停止时取消任务和清理临时目录。
- 生命周期：启动、Socket 就绪、重复启动不产生第二进程、停止、停止状态码、重新启动。
- 打包内容：886 个 ELF 文件均为 x86-64；444 个相对链接均指向包内现存文件。没有打入 Electron、Tauri、用户合同或电脑端运行程序。

- 官方 fnpack 1.2.3 已成功生成 FPK；检查外层与 app.tgz 归档、manifest、相对链接及关键文件哈希，内容与构建目录一致。

## 打包适配

使用 Debian 12 原生组件，随包提供动态加载器和依赖库。LibreOffice 配置改为应用内相对位置，优先加载自己的组件库，并处理首次配置要求重启的返回码。保留中文回退字体和组件许可证。构建固定基础镜像摘要，确切原生包版本在 runtime/debian-packages.txt。

## 仍需目标 NAS 验证

飞牛应用中心安装/卸载、实际统一网关转发与 Socket 访问、系统目录授权 ACL、系统重启后的启动行为、真实大文件性能。Linux 容器验证不能证明这些飞牛系统集成功能已经通过。

实机建议先用普通测试文件：安装后管理员打开应用，转换共享目录内的一份中文文档，再授权一个其他目录验证读写，最后执行停止/启动。原文件和已有导出结果应保留。
